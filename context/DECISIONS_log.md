# Decisions log — PitchPlease

*Append-only. Newest on top. One entry per decision: **YYYY-MM-DD — Bold headline.** Then 1-3 lines: why + revisit trigger.*

---

- **2026-07-09 — Chord drone is a graph layer (bottom sheet), and it outlives the mic.** The dial orders roots by fifths (musical neighbors adjacent), progressions schedule on the audio clock, and `mic.stop()` no longer closes the AudioContext so drones keep sounding through pause/tab switches. Revisit the fifths ordering only if she reads the ring as "alphabet soup."
- **2026-07-09 — Full rebuild: the graph is the app; the session machine is cut, not quarantined.** Three product generations of evidence (journal dead, timed games annoying, tab trainer unloved, graph/tuner/bends loved) say Simone wants an instrument-aware pitch mirror, not a curriculum. Deleted the game cluster, session/profile/generator/evaluator/renderer machinery, drone tab, and tab trainer (git keeps history). Revisit only if she asks for guided practice again — that's a rebuild, priced in.
- **2026-07-09 — Instrument-native rails replace the tab trainer.** The graph's left rail speaks the instrument (harp hole tokens incl. bends, whistle fingerings); a corner HUD names the live note both ways plus harp position. Reading practice = read paper tabs, glance at the mirror. Revisit (tab-as-target-layer) only if this proves insufficient in real use.
- **2026-07-09 — Skins are whole-app looks, not canvas-only themes.** press (ecru print) / neon (phosphor) / riso (violet duotone) each restyle chrome AND canvas via `data-skin` tokens; the old light/dark toggle is gone. Chosen for coherence — a neon trail on paper chrome reads broken. Revisit if she wants to mix.
- **2026-07-09 — `[hidden]` wins by `!important` in reset.css.** Third recurrence of display-defeats-hidden ended structurally; also exactly one view mechanism (`.view.active`, registry in app.js). Never add a per-ID visibility override again.
- **2026-07-09 — Leaving a tab releases the mic; `mic.start()` is idempotent.** Kills stale-flag/double-stream bugs across views. Graph pause holds the trace (pause semantics), so tab-switching costs nothing.
- **2026-07-09 — A4 is a user setting with a measure-my-instrument flow.** Detection AND synth read `settings.a4` (415–466). Calibration plays nothing: it listens, shows mean offset, moves the reference. One global A4 for now; per-instrument offsets only if real use asks.
- **2026-07-09 — Departure Mono (OFL) bundled as the single UI voice.** Pixel-cell humanist mono carries the dithered-print identity; no second font. License shipped at `assets/fonts/DepartureMono-LICENSE.txt`.
- **2026-06-15 — Tab trainer advancement is onset-gated, audio-defined.** A note only counts once the player *arrives* at its pitch (a transition into the target from silence or another pitch). Different notes flow on the pitch change; a repeated same note needs a release + re-attack. Chosen over a tab-annotated release (Simone: "don't rely on the tabs") and over the original pure hold-timer, which let one sustained breath swipe through repeats. Revisit if re-attacks feel too strict at speed (loosen to "left the previous note's zone").
- **2026-06-15 — Tab trainer gets its own `tab-runner`, not the shared exercise-runtime.** Onset gating + manual back/forward nav + live hold dial + no scoring/countdown/reference-tones diverged enough that bending the shared engine added tab-specific coupling and risk to the session features. Dedicated ~150-line controller instead. Revisit if a second feature needs the same advance model (then extract).
- **2026-06-15 — No reference tone in the reading trainer (`audio.playReference:false`).** The runtime sounded the first note as a blip, which both defeats *reading* practice and bled into the mic to auto-advance note one. Reading trainer never sounds the target.
- **2026-06-15 — Library menu is a searchable title list, not notation-preview cards.** Notation on cards was fine for 3 starters; it's noise once the library grows. Cards → search box + title rows (key/difficulty chips only). Revisit never, unless the list stays tiny.
- **2026-06-15 — Library song tabs are "ear-check", brought in by hand.** harptabs blocks bots (403) and bundling a scraped tab DB is a copyright gray area, so Simone pastes tabs in. They're parser-validated for C-harp playability but NOT verified against recordings — wrong notes are source-transcription issues. Revisit per-song if one sounds off.
- **2026-06-12 — Tuner visualizer: horizontal scrolling strip, fixed-center crosshair (Model I).** Chose smooth-scroll (scale slides past a fixed center = your pitch) over a moving-dot/fixed-grid model, because Simone's words were "the whole scale slides" and it avoids the jarring semitone snap at note boundaries. Tradeoff accepted: sharp puts the target tick left-of-center (relative motion) rather than a dot moving right. Revisit if the direction confuses her in real use.
- **2026-06-12 — Default theme flipped to dark.** Simone asked; light (the April overhaul) stays as an opt-in toggle. Noted the reversal at the time; she still wanted dark.
- **2026-06-12 — Graph tap-to-pause aliases the mic toggle, never a second pause state.** Deliberate, to avoid repeating the multi-pause-state bugs (REQ-003/008/012). Center tap = same code path as the mic button + a flash; edge-label press-and-hold-to-drone preserved.
- **2026-06-12 — Journal is dead, permanently.** Simone confirmed: built (REQ-023), cut in the 04-21 overhaul, not coming back. Resolves the open question; supersedes the reconstructed entry below.
- **2026-06-12 — Harmonica pivot: reliability first, then tab-reading trainer.** App was never reliable enough to want to open (all-screens-render bug); pitch viewer + bend trainer are the loved core; timed games felt clunky. New arc: fix P0 bug → C-diatonic tab-reading trainer (untimed, verify-then-advance). Revisit if real use shows the trainer isn't sticky.
- **2026-06-12 — `PRD.md`, `IMPLEMENTATION_PLAN.md`, `CLAUDE.md` stay at repo root.** Archived `do-work/` REQs reference them by path; moving them breaks the trail for zero gain. Revisit if root clutter grows.
- **2026-06-12 — Org layer retrofitted via /newproject.** Domain: personal. Stakeholder: Simone. Project had 81 commits and its own ad-hoc system (PRD, plan, do-work queue) — scaffold wraps it rather than replacing it.
